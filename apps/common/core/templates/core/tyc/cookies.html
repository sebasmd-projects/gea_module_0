1. {% trans 'What this covers' %}

{% blocktrans trimmed %} This policy explains the cookies and similar technologies used by GEA, the platform of Propensiones Abogados available at geausa.propensionesabogados.com and its subdomains. {% endblocktrans %}

2. {% trans 'What we do not use' %}

{% blocktrans trimmed %} We state this first because it is the part that usually matters: this platform carries no analytics, no advertising pixels and no session recording. There is no Google Analytics, no Meta Pixel, no Hotjar and no equivalent. We do not profile visitors, and we do not sell or share browsing data with anyone for advertising. {% endblocktrans %}

3. {% trans 'The cookies we do set' %}

{% blocktrans trimmed %} All of them are strictly necessary: without them you cannot log in, and forms cannot be submitted safely. None of them are used to track you across other sites. {% endblocktrans %}

{% trans 'Cookie' %} {% trans 'What it is for' %} {% trans 'How long it lasts' %}
sessionid {% trans 'Keeps you logged in as you move between pages. Without it, every page would ask for your password again.' %} {% trans 'Until the session expires or you log out' %}
csrftoken {% trans 'Confirms that a form was submitted from this site and not from a page someone else controls.' %} {% trans '1 year' %}
django_language {% trans 'Remembers whether you chose Spanish or English.' %} {% trans '1 year' %}

4. {% trans 'Third parties that see your connection' %}

{% blocktrans trimmed %} Some resources — stylesheets, icon fonts, JavaScript libraries — are served from public content delivery networks. They set no cookies of ours, but by definition they receive your IP address and browser details, because that is how your browser fetches a file from them. {% endblocktrans %}

  • cdn.jsdelivr.net, cdnjs.cloudflare.com — {% trans 'Bootstrap, icons and other libraries.' %}
  • kit.fontawesome.com — {% trans 'icon set.' %}
  • ajax.googleapis.com — {% trans 'the jQuery library, served by Google.' %}
  • fonts.googleapis.com, fonts.gstatic.com — {% trans 'web fonts, where used.' %}
{% trans 'Note for review.' %} {% blocktrans trimmed %} Loading jQuery from Google's CDN gives Google the IP address of every visitor on the pages that use it, without anything being gained over hosting the same file ourselves. Serving those libraries from our own static files would remove that flow entirely, and would also make the platform work when a CDN is unreachable. {% endblocktrans %}

5. {% trans 'Forms hosted by third parties' %}

{% blocktrans trimmed %} Some pages inside the platform embed forms served by JotForm. What you type into one of those forms, including any file you attach, is sent to and stored by that provider, not by us. Their own privacy terms apply to that data in addition to ours. {% endblocktrans %}

6. {% trans 'How to control cookies' %}

{% blocktrans trimmed %} Every browser lets you see, block and delete cookies from its settings. Blocking the three listed above will stop you from logging in and from submitting forms, because they are what makes those operations work at all — it is not a restriction we impose, it is what they are for. {% endblocktrans %}

7. {% trans 'Changes' %}

{% blocktrans trimmed %} If we add any tool that measures or tracks use of the platform, this policy will be updated before that tool is switched on, and consent will be requested where the law requires it. The version and date at the top say which text is in force. {% endblocktrans %}
