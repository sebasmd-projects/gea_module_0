{% load static i18n custom_filters %} {% comment %} Encabezado de las paginas de certificacion. El banner hacia de breadcrumb: era la unica forma de volver, y para saberlo habia que pasar el raton por encima y ver que cambiaba el cursor. Un banner que ademas navega no dice a donde lleva ni en que punto estas. Ahora el banner sigue siendo un enlace --quien ya lo usaba no pierde nada-- pero debajo va un breadcrumb de verdad, con el mismo formato que el resto del panel (`dashboard/partials/header/_header.html`), para no tener dos convenciones distintas en el mismo producto. Parametros: url a donde lleva el banner (obligatorio) parent_title titulo del primer nivel (opcional) parent_url su enlace (opcional) breadcrumbs el resto del camino, separado por '>' (opcional). Cada tramo es "Titulo::/url" o solo "Titulo"; el ultimo se pinta como el sitio donde estas, sin enlace. Ejemplo: {% templatetag openblock %} include '...includes/aegis_header.html' with url=landing_url parent_title='Certificados' parent_url=landing_url breadcrumbs='Verificar documento' {% templatetag closeblock %} {% endcomment %}
